# Trend Slope and Strength — companion data

Portfolio return series and sort diagnostics from **"Trend Slope and Strength"**
(Chad Schmerling, Chicago Booth, and Kingsley Yeon, University of Chicago).
Generated by `gen_website_data.py` in the LinSlope research repo from the
paper-baseline result files. Regenerate by running that script; do not edit
these CSVs by hand.

## Protocol behind every series

| Parameter | Value |
|---|---|
| Universe | CRSP common stock (share codes 10, 11), NYSE/AMEX/NASDAQ, price >= $5 |
| Sample | July 1963 to December 2025 (formation dates); benchmarks start July 1967 |
| Formation window | [t-252, t] trading days, the chart window, no skip month |
| History filter | >= 80% of formation-window days observed |
| Signal | OLS of cumulative return on time: unsigned R² (trend strength) and slope (trend slope) |
| Sort | Conditional 5x5: R² quintiles first (RQ1 low to RQ5 high), slope quintiles within each (SQ1 steepest down to SQ5 steepest up) |
| Holding | 21 trading days, rebalanced monthly, overlapping cohorts averaged |
| Weighting | EW = equal weight, VW = value weight by market cap at formation |
| top500 | Largest 500 stocks by market cap at each formation date |
| TS factor | RQ5/SQ5 minus RQ1/SQ1: long smooth uptrends, short noisy downtrends |
| Factor model | Fama-French 5 + Carhart momentum (FF6), Newey-West HAC with 21 lags on daily data |

All returns are **simple returns in decimal units** (0.01 = 1%), gross of
transaction costs, inclusive of dividends and delisting returns. Daily files
have one row per trading day. Monthly files compound the daily returns within
each calendar month and are stamped with the calendar month-end date.

Long-only portfolio alphas are intercepts on returns in excess of the
one-month T-bill. Long-short spreads are self-financing, so spread alphas are
intercepts on the raw spread. This is the convention used throughout the paper.

## Files

### Headline series

| File | Columns | Description |
|---|---|---|
| `ts_factor_daily.csv`, `ts_factor_monthly.csv` | `date`, `ts_full_ew`, `ts_full_vw`, `ts_top500_ew`, `ts_top500_vw` | The TS factor in four specifications |
| `portfolios25_{full,top500}_{ew,vw}_{daily,monthly}.csv` | `date`, `RQ1_SQ1` ... `RQ5_SQ5` | All 25 conditional double-sort portfolios. `RQ5_SQ5 - RQ1_SQ1` reproduces the TS factor exactly |
| `rolling_ff6_alpha_60m.csv` | `date`, `series`, `window_start`, `n_days`, `ff6_alpha_ann_pct`, `ff6_t_alpha`, `ff6_mom_beta`, `ff6_mkt_beta` | Trailing 60-month daily FF6 regression at each month-end for the four TS series. First estimate January 1968 |
| `summary_stats.csv` | `series`, `start`, `end`, `n_days`, `ann_ret_pct`, `ann_vol_pct`, `sharpe`, `max_drawdown_pct`, `ff6_alpha_ann_pct`, `ff6_t_alpha`, `ff6_mom_beta`, `ff6_r2`, `excess_of_rf_in_regression` | Full-sample statistics for every published series, including each of the 25 cells in each of the four specifications (`RQ{i}_SQ{j}_{universe}_{weighting}`) |

Annualized return is the daily mean times 252. Volatility is the daily standard
deviation times the square root of 252. Alphas are annualized percentages.

### Benchmark spreads

`benchmark_spreads_{ew,vw}_{chartwindow,skip21}_{daily,monthly}.csv`

Decile 10 minus decile 1 long-short spreads on the full universe for the R²
family and for standard momentum-family signals, each computed with the same
sorting machinery. Two formation conventions are provided:

- `chartwindow`: every signal formed on [t-252, t]. This is the paper's
  baseline and matches the horse-race table in the paper.
- `skip21`: every signal formed on [t-252, t-21], the momentum literature's
  skip-month convention. Use these for the conventional momentum definitions.
  `STreversal` (prior-month return) only exists here.

Columns: `R2` (unsigned R²), `SignedR2` (R² times sign of slope), `TSlope`
(t-statistic of the slope; a monotone transform of signed R², so its deciles
and returns coincide with `SignedR2`), `Slope`, `Mom12m`, `Mom6m`, `IntMom`
(months 7-12), `STreversal`, `LRreversal` (months 13-60), `MRreversal`
(months 13-36), `High52` (nearness to 52-week high), `MomVol`, `IndMom`,
`ResidualMom`, `TrendFactor` (Han, Zhou and Zhu 2016). These are the paper's
implementations; see the paper's horse-race section for construction details
before treating them as canonical versions of the published factors.

### Factor-level strategies

`factor_level_ts_{daily,monthly}.csv` with columns `factor_TS`, `factor_PRET`,
`factor_R2`. Applies the TS logic to a 17-factor universe (FF6 plus eleven
horse-race spreads) in the spirit of Ehsani and Linnainmaa (2022): at each
month-end each factor's own cumulative return is regressed on time.
`factor_TS` is long factors with positive slope and above-median R², short
factors with negative slope and above-median R². `factor_PRET` is the plain
factor-momentum baseline. `factor_R2` sorts on R² alone. Starts March 1969.

### Sort diagnostics (for replication without CRSP access)

`breakpoints_monthly.csv`: one row per formation date and universe.
`n_stocks` is the number of stocks with a valid signal. `r2_cut_rq2` ...
`r2_cut_rq5` are the lower edges of R² quintiles 2 to 5.
`slope_cut_rq{i}_sq{j}` for j = 2..5 are the lower edges of slope quintiles
2 to 5 inside R² quintile i. Slope is in cumulative-return units per trading
day (0.001 = 0.1% per day, roughly 25% per year).

`cell_stats_monthly.csv`: one row per formation date, universe, and cell
(`rq`, `sq` from 1 to 5): `n_stocks`, `mean_r2`, `mean_slope`,
`median_slope`, `mean_mcap_musd`, `median_mcap_musd` (market cap in millions
of dollars).

## What is deliberately not here

No stock-level data. Permno-level R², slope, and quintile assignments are
derived directly from licensed CRSP daily returns and are not redistributed.
The breakpoints and cell statistics above are the aggregate substitutes.
The TAQ retail-flow panel used in the mechanism section is likewise licensed
and not included.
